# /sync-tokens

**이 작업을 인라인으로 하지 않는다.** 반드시 `Agent`(subagent_type: `token-guardian`)를 호출한다.
Figma 값을 직접 읽어 손으로 옮겨 적으면 원칙 1(추측 금지)과 레이어 2가 함께 무너진다.

## 절차

### 1. 입력 확인 (호출 전)

| 필요 | 없으면 |
|---|---|
| 대상 Figma 파일 / 변수 컬렉션 | 사용자에게 묻는다 |
| 동기화 방향 | 항상 **Figma → 코드** 단방향. 코드 값을 Figma로 밀어 올리지 않는다 |

Figma MCP가 미인증이면 먼저 인증을 안내하고 중단한다.

하드코딩 매핑만 필요한 경우(Figma 불필요)에는 대상 파일 목록만 정리해 호출한다.

### 2. 에이전트 호출

`Agent`를 `subagent_type: "token-guardian"`로 호출한다. 프롬프트에 반드시 포함할 것:

- 대상 Figma 파일·컬렉션
- "`src/tokens/**` 외 파일은 편집하지 말라"
- "기존 토큰으로 표현되는 값에 새 토큰을 만들지 말라"
- "의미기반 이름으로 적고 Figma 외형 이름을 그대로 옮기지 말라"

### 3. 반환 검증 — 토큰 diff 보고

diff 표(구분 · 토큰 · 이전 값 · 새 값 · 출처 변수)를 사용자에게 그대로 보고한다.

- **값이 변경된 토큰**은 영향 범위(해당 유틸리티를 쓰는 파일)를 함께 보고한다. 색 하나가 바뀌면
  그 토큰을 쓰는 모든 화면이 바뀐다 — 이걸 알리지 않고 넘어가지 않는다
- 에이전트가 보고한 하드코딩 위반 목록은 **여기서 고치지 않는다.** 별도 작업으로 올린다

### 4. 검증 게이트

`/review-design`을 실행한다. 토큰 값 변경으로 깨진 화면이 없는지 확인한다.
