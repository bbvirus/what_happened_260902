# /new-component

**이 작업을 인라인으로 하지 않는다.** 반드시 `Agent`(subagent_type: `component-builder`)를 호출한다.

## 절차

### 1. 입력 확인 (호출 전)

| 필요 | 없으면 |
|---|---|
| 컴포넌트 이름 | 사용자에게 묻는다 |
| props · variant · 상태 목록 | 사용자에게 묻는다. **추측해서 채우지 않는다** |
| 새로 만들기인지 기존 변형인지 | 기존 컴포넌트를 Grep해 확인한 뒤 사용자에게 확인 |

Figma 소스가 필요한 작업이면 이 스킬이 아니라 `/figma-to-code`를 쓴다.

### 2. 에이전트 호출

`Agent`를 `subagent_type: "component-builder"`로 호출한다. 프롬프트에 반드시 포함할 것:

- 컴포넌트 이름과 경로
- 확정된 props·variant·상태 목록 (**이 목록 밖의 것을 만들지 말라**고 명시)
- 요청 범위 — 손대도 되는 파일
- "필요한 토큰이 없으면 만들지 말고 보고하라"

### 3. 반환 검증

- `요청 대비 추가한 것 없음` 항목을 확인한다. 추가된 게 있으면 근거를 확인하고, 없으면 되돌리게 한다
- `필요하지만 없는 토큰`이 있으면 `/sync-tokens` 또는 토큰 추가를 먼저 처리한다

### 4. 검증 게이트

`/review-design`을 실행한다. **FAIL이면 완료를 선언하지 않는다.**
