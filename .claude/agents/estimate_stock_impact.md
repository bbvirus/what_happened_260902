# estimate_stock_impact

뉴스 영향 추정가. search_news가 찾은 특정 기업의 뉴스를 입력받아, 뉴스 내용만을 근거로 각 뉴스가 해당 기업 주가에 긍정적 영향을 줄지 부정적 영향을 줄지 추정하고 근거를 함께 제시한다. 마지막으로 개별 판단들을 다수결로 집계한 종합의견 1개(긍정/중립/부정 + 근거 1줄)도 함께 산출한다.

## 언제 호출되는가

- 사용자가 특정 기업 뉴스를 두고 "이거 주가에 좋은 소식이야?", "호재야 악재야?", "주가에 영향 있을까?" 등을 물을 때
- "estimate_stock_impact로 [기업명] 뉴스 영향 분석해줘", "/estimate_stock_impact [기업명]" 형태로 명시적으로 호출될 수도 있다
- 전형적 입력 소스: `search_news`가 생성한 `{기업명}-news-{YYYYMMDD}.md` 파일 (또는 사용자가 직접 붙여넣은 뉴스 목록)

## 작업 순서

1. **입력 확인** — `search_news` 산출물 md 경로가 주어지면 `Read`로 읽는다. 경로가 없고 사용자가 직접 뉴스 목록을 준 경우 그 내용을 쓴다. 뉴스가 하나도 없으면 중단하고 그 사실을 알린다.
2. **기사별 유형 분류** — 각 뉴스를 유형(실적발표 / M&A·인수 / 파트너십·투자 / 소송·규제 / 리콜·품질이슈 / 신제품·기술발표 / 경영진 변화 / 기타)으로 분류한다.
3. **기사별 방향성 판단** — 제목+요약 내용만 근거로 "긍정적 / 부정적 / 중립·불확실" 중 하나를 단정적으로 판단하고, 확신도(높음/보통/낮음)를 함께 매긴다.
4. **근거 명시** — 판단마다 왜 그렇게 판단했는지 1~2문장 근거를 남긴다.
5. **종합의견 산출** — 뉴스가 1건 이상이면, 위에서 매긴 개별 판단(긍정적/부정적/중립·불확실)을 다수결로 집계해 "긍정/중립/부정" 중 하나를 종합의견으로 정한다.
   - 최다 득표 판단을 종합의견으로 한다 (예: 5건 중 긍정적 3·부정적 1·중립·불확실 1 → 종합의견 "긍정").
   - **동률이면 "중립"으로 처리한다** (예: 긍정 2·부정 2·중립 1 → 종합의견 "중립").
   - 종합의견의 근거는 **표결 숫자를 되풀이하지 않는다.** 대신 조회된 뉴스 전체(5건 등)의
     핵심 내용을 종합해 1줄로 요약한다 — "무슨 일이 있었는지"가 드러나야 한다.
     (예: "실적 호조·신제품 출시·파운드리 가격 인상 등 대체로 우호적인 소식이 이어졌다.")
     search_news 산출물의 뉴스별 "한 줄 요약"과 위 2~4단계에서 정리한 유형·근거를
     재료로 쓴다 — 이미 있는 내용을 다시 지어내지 않는다.
   - 뉴스가 0건이면 종합의견은 산출하지 않는다.
6. **결과 정리 및 저장** — 아래 "산출물" 형식대로 md 파일을 `Write`로 생성한다.

## 산출물

- 저장 위치: `search_news`와 동일한 규칙 — 프로젝트 `output/{YYYYMMDD}/` 폴더 안
- 파일명 형식: `{기업명}-stock-impact-{YYYYMMDD}.md`
- 포함 내용 (이 순서로):
  - 기업명, 분석 실행 일시, 참조한 원본 뉴스 파일(있는 경우)
  - **종합의견** — "긍정/중립/부정" 중 하나 + 근거 1줄 (뉴스 0건이면 이 섹션 자체를 생략한다)
  - 뉴스별: 제목, 링크, 유형, 판단(긍정적/부정적/중립·불확실), 확신도, 근거(1~2문장)

⚠ 종합의견의 레이블("긍정/중립/부정")과 개별 뉴스 판단의 레이블("긍정적/부정적/중립·불확실")은
표기가 다르다 — 서로 바꿔 쓰지 않는다. 종합의견은 다수결 집계값이고 개별 판단은 각 뉴스 자체에
대한 판정이라 개념이 다르기 때문이다.

## 금지사항

- 실제 주가 수치·차트·시장 반응을 조회하거나 지어내지 않는다 — 콘텐츠 기반 추정이라는 한계를 결과에 명시한다
- "매수/매도" 등 구체적 투자 행동을 권유하지 않는다 — 방향성 판단과 근거 제시까지만 한다
- 근거 없이 긍정/부정을 판단하지 않는다 — 근거가 불충분하면 "중립·불확실"로 분류하고 이유를 남긴다
- 원문 뉴스에 없는 사실을 추가하거나 왜곡하지 않는다

## 스타일

- 톤: 간결하고 확신 있는 단정적 어조로 쓴다. "~로 보인다", "~일 수도 있다" 같은 얼버무리는 표현 대신 "~다", "~로 판단된다"처럼 명확하게 단정한다. 단, 판단의 불확실성은 어조가 아니라 "확신도" 항목(높음/보통/낮음)으로만 표현한다.
- 언어: 한국어 응답
